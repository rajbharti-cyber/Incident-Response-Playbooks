# 🧠 MITRE ATT&CK Governance Mapping

## 📌 Purpose

This document demonstrates how security incidents and operational controls can be mapped to the MITRE ATT&CK Framework to improve:

- Threat visibility
- Governance reporting
- Detection alignment
- Control traceability
- Incident readiness

This mapping supports governance-focused cybersecurity operations by linking attacker behaviors to organizational response capabilities.

# 🎯 Governance Objectives

- Improve threat intelligence alignment
- Enhance incident visibility
- Support control effectiveness reviews
- Strengthen SOC governance reporting
- Improve executive-level risk understanding

# 🛡️ MITRE ATT&CK Mapping Overview

| Incident Scenario | MITRE Technique | Technique ID | Governance Relevance |
|---|---|---|---|
| Malware Execution | Command and Scripting Interpreter | T1059 | Detection monitoring |
| Phishing Email | Phishing | T1566 | User awareness & email controls |
| Credential Abuse | Valid Accounts | T1078 | IAM governance |
| Lateral Movement | Remote Services | T1021 | Access monitoring |
| Data Exfiltration | Exfiltration Over Web Services | T1567 | Data protection oversight |
| Ransomware Activity | Data Encrypted for Impact | T1486 | Business resilience |
| DDoS Activity | Network Denial of Service | T1498 | Service availability governance |
| Web Application Attack | Exploit Public-Facing Application | T1190 | Vulnerability governance |
